  SELECT CONCAT('决议application_id列=', COUNT(*)) FROM information_schema.COLUMNS WHERE TABLE_SCHEMA='ccr_rate' AND TABLE_NAME='ccr_resolution' AND COLUMN_NAME='application_id';

## 四、SQL 执行（幂等，推荐直接用汇总文件）

三份脚本均幂等（`INFORMATION_SCHEMA` 动态 DDL / `IF NOT EXISTS` + `INSERT IGNORE` / 条件 `UPDATE`），**重复执行无害**。按文件名升序整跑即可，已具备的列/表自动跳过：

```bash
# 方式一（推荐）:汇总文件一次跑完
docker cp release/ccr_recent_incr_20260902.sql ccr-prod-mysql:/tmp/ccr_recent_incr_20260902.sql
docker exec -i ccr-prod-mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" --default-character-set=utf8mb4 ccr_rate' < /tmp/ccr_recent_incr_20260902.sql

# 方式二:分份执行
for f in db/incr/20260829_001_whole_order_route.sql db/incr/20260829_002_commitment_track.sql db/incr/20260901_001_commitment_track_metric_name.sql; do
  docker exec -i ccr-prod-mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" --default-character-set=utf8mb4 ccr_rate' < "$f"
done
```

**执行后复验**：重跑 §三 的自查 SQL——`整单route_code列=1`、`决议application_id列=1`、`承诺表=1`、`指标名待回刷行=0` 即达标。

> 三份脚本均无规则/矩阵/缓存类配置变更，**无需清理 Redis key**；SQL 变更对后端即时生效。
