> 用途:**数仓对接契约**。数据由内部数据仓库统一加工落地,本系统只消费成果并做快照绑定(D11/D20b),不直接对接外部系统。

### E06 `dw_contribution_metric` 当前贡献度(单指标表,表内勾稽)

| 字段 | 类型 | 说明 |
|---|---|---|
| etl_md5 | BIGINT | 主键 |
| data_dt | DATE | 数据日期 |
| cust_no | VARCHAR(32) | 客户号 |
| metric_code | VARCHAR(40) | **指标编码;TOTAL=综合贡献总额行,其余为明细(对公9项/对私/关联)** |
| metric_name | VARCHAR(64) | 指标名(TOTAL行=综合贡献总额) |
| metric_value | DECIMAL(18,4) | 指标值(万元);TOTAL行=综合贡献总额 |
| value_type | VARCHAR(20) | **AVG_BALANCE业务余额/INCOME收入/CONTRIBUTION_AMOUNT折算(D13)** |
| metric_scope | VARCHAR(15) | **PUBLIC/PRIVATE_SELF/RELATED** |

**勾稽规则(D13b)**:`metric_code='TOTAL'` 的 metric_value 应等于明细行加总;差额0通过、容差内预警、超容差→校验失败(默认阻止提交)。业务余额类(AVG_BALANCE)不得与收入类直接相加为综合贡献。

**指标清单(PRD V2 §9.0)**:
- 对公(PUBLIC):`PUBLIC_DEPOSIT_AVG`存款日均、`PUBLIC_PROJECT_LOAN_AVG`贷款日均、`PUBLIC_DISCOUNT_SPREAD`贴现规模、`PUBLIC_OFF_BALANCE_INCOME`中间业务收入、`PUBLIC_EXCHANGE_SPREAD`结售汇业务总量、`PUBLIC_PAYROLL_CONTRIBUTION`代发客户数、`PUBLIC_PAYROLL_AMOUNT`代发金额、`PUBLIC_WEALTH_INCOME`对公财富中收
- 对私(PRIVATE_SELF):`PRIVATE_DEPOSIT_AVG`对私存款日均、`PRIVATE_LOAN_AVG`对私贷款日均、`PRIVATE_WEALTH_INCOME`对私财富中收
- 派生参考(`value_type='RATIO'`,不参与勾稽):`PUBLIC_DEPOSIT_LOAN_RATIO`存贷比

## 4. 数据质量与提交校验(PRD §8.4)

1. 客户数据存在且证件匹配唯一。
2. 存量客户本行融资合同存在,原利率与合同利率一致。
3. **当前贡献度**未超时效、明细完整且勾稽通过;**拟达成贡献度**须已录入(不做勾稽)。
4. 主客户、关联人当前贡献度统计区间一致。
5. 征信解析完整(无时效限制);不完整时补充证明材料。
6. 人工补录他行融资记录来源方式/操作人/时间/附件(申请级,D13f)。
7. 仓库数据存在阻断级质量问题时阻止提交。
