## 四、SQL 执行（幂等，推荐直接用汇总文件）

两份脚本均幂等（`information_schema` 动态判断，缺列/缺键才 ALTER / 加键），**重复执行无害**。按升序整跑即可：

```bash
# 方式一（推荐）:汇总文件一次跑完
docker cp release/ccr_incr_20260905.sql ccr-prod-mysql:/tmp/ccr_incr_20260905.sql
docker exec -i ccr-prod-mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" --default-character-set=utf8mb4 ccr_rate' < /tmp/ccr_incr_20260905.sql

# 方式二:分份执行
for f in db/incr/20260902_001_credit-resolution-attachment.sql db/incr/20260904_001_branch_type.sql; do
  docker exec -i ccr-prod-mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" --default-character-set=utf8mb4 ccr_rate' < "$f"
done
```

**执行后复验**：重跑 §三 的自查 SQL——`att_source_type列=1`、`att_uk=1`、`branch_type列=1` 即达标。

> **`branch_type` 只加列不回填**：既有 55 家机构一律 NULL=综合，行为与发布前完全一致（两级支行改造不影响既有综合支行/网点/部门）；零售支行后续在机构管理里新增（性质选「零售支行」，父机构须为管理综合支行，创建端校验）。

> 网关决议附件特性**默认关闭**（缺配置不影响既有申请/审批流程）；生产要启用才需在部署侧配置 env，见 §五末。
