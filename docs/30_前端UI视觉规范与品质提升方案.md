## 1. 设计原则

面向银行内部高频作业系统，三个原则：

1. **紧凑高效**：操作员每天看 8 小时，信息密度优先于留白美学——控件 32px、表格行高 40px、卡片间距 12-16px。
2. **克制安静**：颜色只用于状态与关键数据；边框、阴影、徽标全部降一档存在感；页面不"跳"。
3. **一致可预期**：全站只有三类页面模板（列表/录入/详情），同类元素长在同位置、同样式。

## 2. 视觉规范（token 级，拟进 design-system.css）

| 项 | 现状 | 精修后 | 说明 |
|---|---|---|---|
| 边框 | `--color-border` 偏深 | `#e6eaf0` / 浅 `#eef1f5` | 卡片与输入框降存在感 |
| 阴影 | 卡片带悬停浮起 | 静态柔阴影，取消 hover 浮起 | 后台系统不需要"卡片会动" |
| 底色 | `--color-bg` | `#f5f6f8` 暖灰 | 白卡片更分明 |
| 控件 | 36px / 14px | **32px / 13px**，圆角 6px | 密度提升一档（申请页已试点 `.form-compact`，本方案全站推广） |
| label | 14px 深色 | 12px `#8a94a6` 弱色 | 视线焦点让给输入值 |
| 按钮 | 高度不一 | 统一 32px；主=实心蓝，次=描边，文字=弱色 | 一个操作区只允许一个主按钮 |
| 表格 | 行高偏大 | 行高 40px、表头 `#fafbfc` 12px 弱色、行 hover `#f8fafc`、数字右对齐等宽 | 金额利率类列一律等宽数字 |
| 徽标 | 偏大偏艳 | 11px、圆角 4、低饱和底色 | 只表达状态，不作装饰 |
| 圆角 | 10/16 混用 | 卡片 8、控件 6、徽标 4 | 层级越小圆角越小 |

## 3. 三类页面模板（全站统一骨架）

**列表页**（审批列表/历史/审计/系统管理各页）：查询区（一行可换行，label 置上）→ 工具条（左标题右主操作）→ 表格（40px 行高 + 横滚兜底）→ 分页右下。
**录入页**（loan/deposit）：步骤条 → 卡片分组（`form-group-title`）→ 吸底操作条。控件密度用紧凑档。
**详情页**（审批详情/档案）：吸顶摘要条 + 锚点 → 五段分区 → 吸底操作条。

查询区目前是每个页面私造（run-log 的 `.query-bar`、audit 的同形私造都没沉淀）——补一个 `.query-bar` 公共类收尾。

## 4. 组件补齐清单（design-system 缺口）

| 组件 | 缺口 | 处置 |
|---|---|---|
| `.query-bar` 查询区 | 各页私造 | 沉淀：一行 flex、label 置上、输入 220px 基准宽、按钮右对齐 |
| 弹窗 | 宽度随意 | 三档规范：表单弹窗 560 / 宽表弹窗 860 / 确认弹窗 420 |
| 表格内编辑 | 申请页明细表 input 直接塞单元格 | 单元格输入去边框、聚焦才显示描边 |
| 空态 | `.empty` 插画 / `.empty-line` 混用规则不明 | 规则：整块无数据用 `.empty`，卡内局部无数据用 `.empty-line` |
| 纵向时间轴 | history 页私造 | 保留页面私有（与横向 `.flow-steps` 语义不同），不强行统一 |

## 5. 实施分期

| 期 | 内容 | 风险 | 粗估 |
|---|---|---|---|
| V1 | design-system token 精修（§2 全表）+ `.query-bar` 沉淀 + 弹窗三档规范 | 纯 CSS 变量与新增类，低风险；逐页回归 | 1–2 天 |
| V2 | 列表页模板套用（9 个列表/管理页） | 低 | 1–2 天 |
| V3 | 录入页/详情页密度与表格内编辑优化 | 中（申请表单密集），重点回归 loan/detail | 1–2 天 |

## 6. 决策点

| # | 问题 | 建议 |
|---|---|---|
| V-D1 | 精修 token 直接改 design-system 变量（全站即时生效）还是新加修饰类逐页推广？ | 边框/阴影/底色这类"降存在感"的直接改变量；控件尺寸经 `.form-compact` 逐页推广（已在申请页验证） |
| V-D2 | 表格是否加斑马纹 | 建议不加，行 hover 即可（斑马纹与选中高亮叠加反而乱） |
| V-D3 | 品牌蓝 `#1890ff` 是否保留 | 保留（全站记忆成本低），仅降辅助色饱和度 |
