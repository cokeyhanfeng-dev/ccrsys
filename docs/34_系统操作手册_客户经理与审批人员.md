# 客户贡献度与利率决策系统 · 操作手册

> 适用对象：客户经理、支行行长、部门总经理、分管行领导、六人小组委员、总行行长
> 版本：2026-09-03 ｜ 系统入口：http://localhost:3000（行内地址以信息科通知为准）
> 支持：使用中遇到问题请联系系统管理员或信息科

---

## 一、登录与角色

1. 打开系统地址，输入**工号**和**密码**登录。初始密码由管理员发放，首次登录后请通过右上角头像 →「修改密码」自行修改。
2. 关闭浏览器后需重新登录（登录态不跨浏览器会话保留）。
3. 你能看到哪些菜单由你的角色决定，看不到的菜单就是没有权限，属正常现象。

| 角色 | 你主要干什么 |
|---|---|
| 客户经理 | 新建贷款/存款利率申请、跟踪审批进度、录入贡献承诺 |
| 支行行长 | 审批本支行提交的申请（第一关） |
| 部门总经理 | 审批权限内的申请（公司金融部/授信评审部/零售金融部分流） |
| 分管行领导 | 审批超部门权限的申请 |
| 六人小组委员 | 对上会申请投同意/否决票 |
| 总行行长 | 对表决通过的申请做最终决策（同意/一票否决） |

## 二、客户经理操作指南

### 2.1 工作台

登录后默认进入工作台：左侧是「我的申请动态」和快捷入口，右侧是「待我处理」和「承诺跟踪概况」。有退回/临期提醒会直接出现在「待我处理」里。

### 2.2 新建贷款利率申请（六步向导）

点击侧栏「贷款利率申请」，按步骤填写，每步填完点底部「下一步」，中途可随时「存草稿」。

**第 1 步 客户信息**
- 先选客户主体：单户企业 / 个人 / 集团客户。
- 输入客户名称会自动联想数仓客户；数仓查不到的新客户可手工补录（带"数仓未收录"标记，提交时按人工补录口径处理）。
- 证件号/统一社会信用代码**必填**。
- **集团客户**：选中集团后显示集团档案（授信额度、可用额度等）；在成员列表里**勾选本次涉及的成员**（勾选结果决定第 4 步的分项页签）。数仓没有的手工成员可点「手工补录成员」弹窗补录。

**第 2 步 关联人员**
- 录入与本笔业务相关的配偶/直系亲属/担保人等；证件号填完失焦自动判重并绑定，已绑定其他客户的证件号会标红拦截。
- 没有可跳过。

**第 3 步 融资情况**
- 他行融资概要 + 明细（明细可用 Excel 模板批量导入）。
- 概要与明细的授信总额/已用额/机构数/笔数必须一致，不一致提交时会被拦截。

**第 4 步 利率申请（核心）**
- 业务类型：存量调息（现有贷款合同）/ 新增授信。
- **存量调息**：授信协议区为一张表——在「授信协议编号」列的下拉里选协议号，选中后同一行带出该协议的总额/日期/状态/到期日。每份协议独立申请，不可合并。
- **担保分项**：按担保方式拆分（抵押/质押/保证/信用/保证金等），每个分项填期限、授信金额、申请利率、测算利率。
  - 集团客户：顶部是成员页签（每个成员一个页签，角标显示分项数，0 项黄色提醒），页签内「＋添加分项」直接给该成员加分项；也可用「为每个成员生成一个分项」一键补齐。
  - 顶部勾稽条实时显示「成员金额合计 vs 本次申请额度」，超额会标红，提交会被拦截。
- 协议区下方有「综合利率」自动计算（按分项金额×利率加权），供参考。

**第 5 步 承诺与材料**
- 录入拟达成贡献承诺：选指标、填目标值和截止日期（必填）。目标类型只有三种：目标余额/笔数/比例。
- 上传申请材料附件。

**第 6 步 提交预览**
- 内联显示申请概要和分项明细，确认后点「提交申请」；系统会弹提交前校验（数据批次差异/质量预校验/硬边界提示），有阻断项会红字标明，按提示返回修改；无阻断项确认提交。

### 2.3 新建存款利率申请

流程与贷款类似但更简单（不分步）：客户信息 → 存款分项（选存款账户/产品/期限，填申请利率）。
**注意**：申请利率必须**高于**该产品期限档的挂牌起点利率，等于挂牌价无需提交申请（柜面直接办理）；超过产品上限的申请自动上六人小组表决。

### 2.4 提交后

- 工作台「我的申请动态」看进度；被退回会出现在「待我处理」，点开按退回意见修改后**重新提交**。
- 被否决/已终态的申请不可修改，可在历史申请里「关联重提」生成新草稿。

### 2.5 贡献度跟踪

侧栏「贡献度跟踪」：每行一条承诺，显示目标值、当前实际值（数仓最新数据）、完成比例、截止日期、状态。
- 跟踪中：实时完成度（含该申请关联人的同指标贡献，一并计入）。
- 到期后系统自动定案：完成比例 ≥100% 为「已完成」，否则「未完成」。定案结果不可更改。

## 三、审批人员操作指南（支行行长/部门总经理/分管行领导）

### 3.1 待办

侧栏「利率审批」进入待办列表，只看到分配给你的节点和机构的申请。

### 3.2 审批详情页

点开一笔申请：

- **页头**：客户名 + 当前节点 + 申请号/业务类型/金额/时间；下方页签可跳转各区块。
- **申请内容**：分项明细表（金额/利率/当前节点/状态），点「明细 ▸」展开更多字段。
- **客户与集团 / 承诺与履约 / 流程轨迹**：只读参考，低频资料默认折叠，需要再展开。
- **流程轨迹**：步骤条显示当前走到哪个节点，下面是逐条留痕。

### 3.3 审批动作（页面底部固定操作条）

1. 在输入框填审批意见（**否决时必填原因**）。
2. 点「**同意**」或「**否决**」：
   - 你所在节点有终审权时，同意即终审通过；无终审权时同意=过手，申请自动送下一节点。
   - 否决即整单否决，申请终止并退回申请人。
3. **调价**：你有权调价时，分项的"审批后利率"可以直接改（受节点权限边界约束，超出会被拦截）。

注意：一旦提交动作不可撤销，请确认意见和利率无误。

## 四、六人小组委员操作指南

1. 侧栏「六人表决」进入待表决列表。
2. 点开申请查看完整内容（委员视图只读，不能调价）。
3. 底部操作条投「**同意**」或「**否决**」票。每个申请只能投一次，投后不可改。
4. 计票规则：6 名委员全部投完后自动计票，**赞成 ≥4 票通过**，不足 4 票即未通过（申请整单否决）；通过后进总行行长决策。
5. 你的投票对其他委员匿名（行长和审计可匿名查看意见分布）。

## 五、总行行长操作指南

1. 侧栏进入行长决策待办。
2. 查看申请全貌 + 表决结论（计票结果 + 委员匿名意见）。
3. 底部操作条：填意见后点「**同意**」即终审通过；「**否决**」（一票否决，**必须填意见**）则申请终止。

## 六、常见问题（先看这里）

| 现象 | 原因与处理 |
|---|---|
| 提交提示"请录入客户证件信息" | 第 1 步客户信息里补统一社会信用代码/证件号 |
| 提交提示"分项金额合计与授信总额不一致" | 调整分项金额，使合计=本次申请额度（集团单看第 4 步勾稽条） |
| 提交提示"一合同/账户只允许一个有效分项" | 该合同/存款账户已有在途申请，等它终态后再提 |
| 存款提交提示"必须高于起点利率" | 申请利率要高于挂牌价；等于挂牌价无需申请 |
| 提示"硬边界/突破上限"类展示 | 仅为提示不拦截，可正常提交（由路由决定审批层级） |
| 看不到待办 | 该申请不在你的节点/机构；或角色不符 |
| 贡献度跟踪显示"暂无数据" | 数仓当天未推送该客户该指标，次日再看；长期无数据联系数据中心 |
| 页面样式异常/旧页面 | 强制刷新浏览器（Ctrl+F5） |

## 七、注意事项

- 所有审批、表决、决策动作**全程留痕**，不可删除修改，请谨慎操作。
- 草稿只保存主单信息，建议一次性填完再提交。
- 数仓数据每天更新一次，页面上的"数据日期"显示了当前数据的日期。
