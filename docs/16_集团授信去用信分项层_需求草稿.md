# 需求：集团授信去掉「用信分项」中间层(2026-08-17)

> 状态：**已确认并实施**（任务 #111-#115）。四个决策点已确认：D1 种子删建表/运行库表保留；D2 合同表 `tranche_no` 保留列不填；D3 审批展示层 `trancheNo` 保留；D4 新增引用走成员额度+系统内定价分项。
> 涉及隐私：本文件仅本地 commit,不 push GitHub。

---

## 一、背景与业务逻辑澄清

**业务现状（用户澄清）**：集团授信层级**实际只有三层**：

```
集团总授信 → 切分授信(按公司,即成员额度) → 贷款合同 → 借据
```

- 存量授信：切分授信（成员额度）下**直接放合同/贷款**，**没有「用信分项」这一层**。
- 「用信分项」概念只用于**新增授信业务**：新增申请时没有合同，用**系统内定价分项**（`ccr_pricing_item`）承载，与单户申请一致。

**问题**：当前系统与数仓契约中存在 `dw_credit_tranche_snapshot`（B06 用信分项）中间层，并据此设计了采集/引用/监控逻辑。该层在业务上**无存量数据来源**、且新增承载已由系统内定价分项承担，属于**假设出来的冗余层**，需去除。

**数仓答疑结论**：按上述逻辑，数仓**不需要提供** B06；`dw_loan_contract_snapshot.tranche_no` 存量**不填**。
