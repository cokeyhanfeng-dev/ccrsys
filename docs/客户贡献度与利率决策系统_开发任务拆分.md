  - 产品配置 CRUD + 版本发布（§8A.2 状态机，admin 配置即可）；产品目录与产品边界（`ccr_product_rate_limit`）关联校验（边界产品必须为启用产品）。
- **依据**：§8A.5、§10.3.22-23、§11.9
- **涉及 API**：`/api/v1/config/product*`、`/api/v1/config/product-route*`（含模拟路由）
- **依赖**：T8.1、T1.1
- **验收**：产品目录 CRUD + 启停；产品审批链路 CRUD + 发布 + 模拟路由；产品停用后新申请阻断；路由引擎按产品命中链路（供 T2.3 联调）。
