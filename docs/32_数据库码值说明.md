# 数据库码值说明

> 覆盖：全库主要业务码值(状态机 / 字典 / 枚举字段)。字典源：`ccr_dict_type` + `ccr_dict_item`(共 19 个字典)；枚举源：DDL COMMENT。
> 单位约定：金额 DECIMAL(20,4) 单位万元；利率 DECIMAL(9,6) 为百分值(展示乘 100)；日期 DATE/DATETIME。

## 一、核心状态机

### `ccr_application.status` 申请状态

DRAFT草稿 / SUBMITTING提交中 / PROCESSING审批中 / PARTIAL_APPROVED部分通过 / APPROVED全部通过 / REJECTED全部否决 / CLOSED关闭

### `ccr_pricing_item.status` 定价分项状态

DRAFT草稿 / ROUTING路由中 / LEVEL_APPROVAL权限审批 / VOTING小组表决 / PRESIDENT_DECISION行长决策 / APPROVED通过 / REJECTED否决 / VETOED一票否决 / SUPERSEDED被取代 / CLOSED关闭

### `ccr_vote_round.status` 表决轮次状态

CREATED已创建 / VOTING表决中 / COUNTING计票中 / PASSED通过 / FAILED未通过 / CANCELLED已取消

### `ccr_resolution.execution_status` 决议执行状态

ISSUED已签发 / CONTRACT_PENDING待回填合同 / CONTRACT_BOUND已绑定合同 / EXECUTED已执行 / RECONCILE_EXCEPTION对账异常 / CLOSED已关闭

### `ccr_commitment_track.status` 承诺跟踪状态

TRACKING跟踪中 / FINISHED_MET已完成 / FINISHED_UNMET未完成

### `ccr_commitment_track.target_kind` 承诺目标类型

BALANCE目标余额 / COUNT笔数 / RATIO比例

> 承诺预警链路 `ccr_tracking_status`：PENDING未开始 / TRACKING跟踪中 / AT_RISK有风险 / ACHIEVED已达成 / EXPIRED_UNMET到期未达成 / DATA_PENDING数据待批 / TERMINATED已终止 / SUPERSEDED被取代

## 三、其他枚举字段(DDL 定义)

### `ccr_application.business_type` 业务类型

LOAN贷款 / DEPOSIT存款

### `ccr_application.customer_scope` 客户主体范围

INDIVIDUAL个人 / CORPORATE_SINGLE企业单户 / GROUP集团

### `ccr_pricing_item.pricing_carrier_type` 执行载体类型

LOAN_CONTRACT贷款合同 / DEPOSIT_ACCOUNT存款账户

### `ccr_pricing_item.rate_direction` 利率比较方向

LOWER_BETTER越低越好 / HIGHER_BETTER越高越好

### `ccr_pricing_item.inherit_flag` 沿用原决议

Y沿用 / N不沿用

### `ccr_application.operation_channel` 操作渠道

PC / MOBILE

### `ccr_resolution.decision_source` 决议来源

VOTE_APPROVED表决通过 / PRESIDENT_APPROVED行长批准 / LEVEL_APPROVED权限审批通过 / COMMITTEE_REJECT小组否决

### `ccr_application_guarantee.main_guarantee_type` 担保主类型

CREDIT信用 / GUARANTEE保证 / MORTGAGE抵押 / PLEDGE质押 / BILL_MARGIN银票保证金 / CREDIT_MARGIN信用证保证金 / CERTIFICATE_DEPOSIT存单质押

### `ccr_rate_matrix.business_big_type` 矩阵业务大类

LOAN_PUBLIC对公贷款 / LOAN_PERSONAL个人贷款 / DEPOSIT存款 / MARGIN保证金

### `ccr_rate_matrix.new_or_existing` 新增/存量

NEW新增授信 / EXISTING存量授信

### `ccr_rate_matrix.customer_type` 客户类型

SOE国企 / NON_SOE非国企 / PERSONAL个人(空=通配)

### `ccr_rate_matrix.start_node_code` 终审岗位

BRANCH_MANAGER支行行长 / DEPT_GENERAL_MANAGER部门总经理 / VICE_PRESIDENT分管行长 / SIX_PEOPLE_GROUP六人小组

### `ccr_rate_matrix.boundary_type` 边界语义

RATE直接利率 / SPREAD降幅(存量)

### `ccr_product.mandatory_vote / president_decision` 强制机制

Y/N(对公贷款>5000万强制小组 / 必经总行行长决策)

### `ccr_node_assignee.assignee_type` 审批人分配类型

PERSON按人 / GROUP按组(角色集合,逗号分隔) / DEPT按机构 / ROLE按角色兜底

### `ccr_commitment.trigger_level` 预警触发等级

WATCH关注 / AT_RISK有风险 / EXPIRED到期

### `ccr_commitment.recipient_type` 通知对象类型

CUSTOMER_MANAGER/GROUP_MANAGER/MEMBER_MANAGER/BRANCH_MANAGER/GROUP_ORG_LEADER/ORIGINAL_APPROVER/ORIGINAL_VOTER/DEPT_GM/VICE_PRESIDENT/ROLE/USER/ORG_POST

### `ccr_commitment.allocation_mode` 承诺分配方式

FIXED_ALLOCATION固定分配 / GROUP_SHARED集团共享

### `ccr_metric_definition.metric_scope` 指标范围

PUBLIC对公 / PRIVATE_SELF个人对私 / RELATED关联 / GROUP集团 / GROUP_MEMBER集团成员

### `ccr_snapshot_conflict.confirm_status` 人工确认状态

UNCONFIRMED未确认 / CONFIRMED已确认

### `ccr_sys_user.status` 用户状态

ENABLE启用 / DISABLE停用

### `ccr_sys_user.pwd_change_flag` 强制改密

1需改密 / 0已改

### `ccr_sys_role.role_code` 角色

customer_manager客户经理 / branch_manager支行行长 / dept_gm部门总经理 / vice_president分管行长 / committee_member六人小组成员 / president行长 / admin管理员

### `ccr_dict_type.status` 字典类型状态

ENABLED/DISABLED(停用后新申请不可选)

### `ccr_product.status` 产品状态

ENABLED/DISABLED

### `ccr_snapshot_dataset.sensitive_level` 敏感等级

NONE明文 / CIPHER密文 / HASH哈希

### `ccr_application_relation.relation_type` 关联申请类型

REAPPLY重提 / REPLACE替换

### `ccr_customer_relation.relation_type` 客户关系类型

配偶/直系亲属/担保人/实际控制人等

### `ccr_audit_log.send_status` 消息发送状态

SUCCESS成功 / FAILED失败 / RETRYING重试中

### `ccr_notification.status` 通知状态

PENDING待发送 / SENT已发送 / FAILED失败 / DELIVERED已送达

### `ccr_outbox_message.status` 消息箱状态

PENDING待发送 / SUBMITTED已提交 / REPLACED被替换

### `ccr_outbox_message.send_status` 消息箱发送状态

SENDING发送中 / SENT已发送 / FAILED失败 / RECEIVED已接收 / ARCHIVED已归档

### `ccr_metric_definition.status` 指标定义状态

DRAFT草稿 / REVIEW评审中 / EFFECTIVE生效 / INVALID停用

### `ccr_rate_rule.status` 利率规则状态

DRAFT草稿 / REVIEW评审中 / EFFECTIVE生效 / INVALID停用(默认EFFECTIVE)

### `ccr_validation_report.result_status` 勾稽结果

PASS通过 / WARN预警 / FAILED失败

### `ccr_validation_report.reconcile_result` 对账结果

PASS / WARN / FAILED

### `ccr_validation_level` 校验等级

PASS通过 / WARN预警 / BLOCK阻断

### `ccr_rate_matrix.status` 矩阵行状态

ACTIVE有效 / INACTIVE停用(废弃不删)

### `ccr_flow_task.status` 流程任务状态

CREATED已创建 / VOTING表决中 / COUNTING计票中 / PASSED通过 / FAILED未通过 / CANCELLED已取消

### `ccr_resolution.status` 决议状态

CREATED已创建 / VOTING表决中 / COUNTING计票中 / PASSED通过 / FAILED未通过 / CANCELLED已取消

### `ccr_record_status` 记录状态

ACTIVE有效 / INACTIVE失效 / DELETED已删除

### `ccr_currency` 币种

CNY人民币 / USD美元 / EUR欧元

### `ccr_term_unit` 期限单位

DAY日 / MONTH月 / YEAR年

### `ccr_metric_definition.business_big_type` 指标业务大类

LOAN贷款 / DEPOSIT存款(空=全行默认)

### `ccr_metric_definition.threshold_type` 指标阈值类型

TIME_PROGRESS时间进度 / ACHIEVEMENT_RATE达成率 / CONSECUTIVE_DECLINE连续下滑 / NEAR_EXPIRY临近到期

### `ccr_product.lpr_term` LPR期限

1Y / 5Y+

## 四、审批节点码(ccr_node_code)

| 节点编码 | 名称 | 说明 |
|---|---|---|
| `BRANCH_MANAGER` | 支行行长 | 必经首节点(贷款/存款恒为首节点) |
| `DEPT_GENERAL_MANAGER` | 部门总经理 | 按部门归属(dept_code)分流 |
| `VICE_PRESIDENT` | 分管行长 | 按部门归属(dept_code)分流 |
| `SIX_PEOPLE_GROUP` | 六人小组 | 表决节点(委员投票) |
| `PRESIDENT` | 总行行长 | 行长决策节点 |
| `SECRETARY` | 秘书岗 | 整单门槛(VP 齐套任一命中秘书岗则整单先到秘书岗) |
