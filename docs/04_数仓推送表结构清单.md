# 客户贡献度与利率决策系统 · 数仓推送表结构清单(提交数仓加工)

> 依据:《ccrd_dw_schema _修订.sql》(v1.1 / PRD V2 D1-D21)
> 用途:**申请时按客户姓名模糊查询带出客户信息**,以及审批所需的融资/担保/贡献度/征信/机构达成数据。本清单供数仓加工落地。
> 交付方:客户贡献度与利率决策系统(业务系统)
> 版本: v1.0 / 2026-08-06

---

## 〇、总览(共 10 张推送表)

| # | 表名 | 说明 | 用途 | 时效 |
|---|---|---|---|---|
| T01 | `caps_corp_cust_basic_info` | 对公客户主数据 | 申请按客户姓名模糊查询带出 | 每日 |
| T02 | `caps_indv_cust_basic_info` | 对私客户主数据 | 申请按客户姓名模糊查询带出 | 每日 |
| T03 | `dw_own_financing_snapshot` | 本行融资合同 | 存量授信/原利率来源 | 每日 |
| T04 | `dw_mortgage_snapshot` | 抵押物 | 担保展示/补充 | 每日 |
| T05 | `dw_guarantor_snapshot` | 担保人 | 担保展示/补充 | 每日 |
| T06 | `dw_contribution_metric` | 当前贡献度(单指标,勾稽) | 贡献度卡片/承诺跟踪 | T+1 |
| T07 | `dw_credit_report_snapshot` | 征信报告头 | 征信展示 | 无时效 |
| T08 | `dw_credit_financing_detail` | 征信他行融资明细 | 他行融资 | 无时效 |
| T09 | `dw_credit_financing_summary` | 他行融资概要 | 他行融资概要 | 无时效 |
| T10 | `dw_org_performance_snapshot` | 机构达成 | 机构达成率 | 月度 |

**通用约定**:字符集 utf8mb4;金额 `DECIMAL(18,4)`(万元);利率 `DECIMAL(7,4)`(百分值,如 3.8500=3.85%);敏感证件列**密文落库 + 查询哈希**;每表以 `etl_md5` 为主键 + `data_dt` 标识批次,业务读取最新 `data_dt` 批次。

## T01 `caps_corp_cust_basic_info` 对公客户主数据 ⭐(姓名模糊查询核心)

```sql
CREATE TABLE caps_corp_cust_basic_info (
  etl_md5           CHAR(32)     NOT NULL COMMENT '源系统ETL_MD5(主键)',
  data_dt           DATE         NOT NULL COMMENT '数据日期',
  cust_no           VARCHAR(32)  NOT NULL COMMENT '客户号',
  cust_name         VARCHAR(128) NOT NULL COMMENT '客户名称',
  cert_tp           VARCHAR(10)  NOT NULL COMMENT '证件类型',
  cert_no           VARCHAR(512) NOT NULL COMMENT '统一社会信用代码(密文)',
  ffthlv_class      VARCHAR(10)  NULL COMMENT '客户五级分类',
  entp_charic       VARCHAR(20)  NULL COMMENT '企业性质(国企/非国企)',
  entp_scale        VARCHAR(20)  NULL COMMENT '企业规模',
  blgd_idsty        VARCHAR(20)  NULL COMMENT '所属行业',
  crdt_grd          VARCHAR(10)  NULL COMMENT '内部信用等级',
  entp_empe_num     INT          NULL COMMENT '员工人数',
  rest_addr         VARCHAR(256) NULL COMMENT '注册地址',
  rest_asts         DECIMAL(18,4) NULL COMMENT '注册资本(万元)',
  estp_estb_dt      DATE         NULL COMMENT '成立日期',
  openact_org_no    VARCHAR(32)  NULL COMMENT '开户机构编号',
  openact_org_nm    VARCHAR(32)  NULL COMMENT '开户机构名称',
  openact_dt        DATE         NULL COMMENT '开户日期',
  cust_class        VARCHAR(10)  NOT NULL COMMENT '客户性质:EXISTING存客/NEW新客',
  PRIMARY KEY (etl_md5),
  KEY idx_cust_no (cust_no),
  KEY idx_cert_no (cert_no),
  KEY idx_cust_name (cust_name)          -- ⭐ 客户姓名模糊查询索引
);
```

## T02 `caps_indv_cust_basic_info` 对私客户主数据 ⭐(姓名模糊查询核心)

```sql
CREATE TABLE caps_indv_cust_basic_info (
  etl_md5           CHAR(32)     NOT NULL COMMENT '源系统ETL_MD5(主键)',
  data_dt           DATE         NOT NULL COMMENT '数据日期',
  cust_no           VARCHAR(32)  NOT NULL COMMENT '客户号',
  cust_nm           VARCHAR(128) NOT NULL COMMENT '客户姓名',
  cert_tp           VARCHAR(10)  NOT NULL COMMENT '证件类型',
  cert_no           VARCHAR(512) NOT NULL COMMENT '证件号(密文)',
  gnd               CHAR(64)     NOT NULL COMMENT '性别',
  ffthlv_class      VARCHAR(10)  NULL COMMENT '五级分类',
  ocupn             VARCHAR(40)  NULL COMMENT '职业',
  whlyr_incm        DECIMAL(18,4) NULL COMMENT '全年收入(万元)',
  mrrg_sittn        VARCHAR(10)  NULL COMMENT '婚姻状况',
  rsd_addr          VARCHAR(256) NULL COMMENT '居住地址',
  tel_no            VARCHAR(32)  NULL COMMENT '联系电话',
  opnact_org_no     VARCHAR(32)  NULL COMMENT '开户机构编号',
  opnact_org_nm     VARCHAR(32)  NULL COMMENT '开户机构名称',
  opnact_dt         DATE         NULL COMMENT '开户日期',
  cust_class        VARCHAR(10)  NOT NULL COMMENT '客户性质:EXISTING存客/NEW新客',
  PRIMARY KEY (etl_md5),
  KEY idx_cust_no (cust_no),
  KEY idx_cert_no (cert_no),
  KEY idx_cust_nm (cust_nm)              -- ⭐ 客户姓名模糊查询索引

```

> **申请带出逻辑**:客户经理输入客户姓名 → `LIKE '%姓名%'` 模糊查询 → 带出客户号、证件、客户性质、开户机构、五级分类/信用等级/企业性质/注册资本等,作为申请客户信息(只读展示)。

## T03 `dw_own_financing_snapshot` 本行融资合同

```sql
CREATE TABLE dw_own_financing_snapshot (
  etl_md5           BIGINT  NOT NULL AUTO_INCREMENT,
  data_dt           DATE    NOT NULL,
  cust_no           VARCHAR(32) NOT NULL COMMENT '客户号',
  contract_no       VARCHAR(32) NOT NULL COMMENT '授信合同号',
  crgant_start_dt   VARCHAR(32) NULL COMMENT '授信开始日期',
  crgant_due_dt     VARCHAR(32) NULL COMMENT '授信到期日期',
  crgant_matu       INT     NOT NULL COMMENT '授信期限',
  guarantee_type    VARCHAR(10) NOT NULL COMMENT '担保类型',
  loan_balance      DECIMAL(18,4) NOT NULL COMMENT '贷款余额(万元)',
  contract_rate     DECIMAL(7,4)  NOT NULL COMMENT '原利率%(本行合同当前利率)',
  PRIMARY KEY (etl_md5),
  KEY idx_cust (cust_no),
  KEY idx_contract (contract_no)
);
```
> 存量授信申请按此表合同切分额度;`contract_rate` 作为申请原利率。

## T06 `dw_contribution_metric` 当前贡献度(单指标,表内勾稽)

```sql
CREATE TABLE dw_contribution_metric (
  etl_md5           BIGINT  NOT NULL AUTO_INCREMENT,
  data_dt           DATE    NOT NULL,
  cust_no           VARCHAR(32) NOT NULL,
  metric_code       VARCHAR(40) NOT NULL COMMENT '指标编码;TOTAL=综合贡献总额行,其余为明细(对公9项/对私/关联)',
  metric_name       VARCHAR(64) NOT NULL,
  metric_value      DECIMAL(18,4) NOT NULL COMMENT '指标值(万元);TOTAL行=综合贡献总额',
  value_type        VARCHAR(20) NOT NULL COMMENT 'AVG_BALANCE业务余额/INCOME收入/CONTRIBUTION_AMOUNT折算',
  metric_scope      VARCHAR(15) NOT NULL COMMENT 'PUBLIC/PRIVATE_SELF/RELATED',
  PRIMARY KEY (etl_md5),
  KEY idx_cust (cust_no),
  KEY idx_cust_code (cust_no, metric_code)
);
```
> 指标清单(PRD §9.0):对公 `PUBLIC_DEPOSIT_AVG/PROJECT_LOAN_AVG/DISCOUNT_SPREAD/OFF_BALANCE_INCOME/EXCHANGE_SPREAD/PAYROLL_CONTRIBUTION/PAYROLL_AMOUNT/WEALTH_INCOME`;对私 `PRIVATE_DEPOSIT_AVG/LOAN_AVG/WEALTH_INCOME`;派生参考 `PUBLIC_DEPOSIT_LOAN_RATIO`(RATIO,不参与勾稽)。TOTAL 行与明细行须勾稽一致。

## 附:提交前必做校验(PRD §8.4)

1. 客户数据存在且证件匹配唯一。
2. 存量客户本行融资合同存在,原利率与合同利率一致。
3. 当前贡献度未超时效、明细完整且勾稽通过。
4. 主客户、关联人当前贡献度统计区间一致。
5. 征信解析完整(无时效限制)。
6. 仓库数据存在阻断级质量问题时阻止提交。
