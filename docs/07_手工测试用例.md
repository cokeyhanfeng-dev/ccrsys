## 场景 A：对公非国企新增贷款——支行行长权限内终审（最短链路）

1. `zhangsan` 登录 → 贷款利率申请 → 客户类型"企业单户"，查 CUST001（输客户号或姓名均可）带出；确认"申请机构"显示**城东支行**（只读）
2. 融资情况步骤选"新增授信"，拟签合同；担保方式选"抵押"，抵押物选类型（如住宅）录名称/坐落/面积/产权证号/估值；不点下一步直接跳步，**预期分步校验提示当前步骤必填项**
3. 利率定价：产品=**对公贷款（LOAN_A）**，金额 3000 万，期限 1 年，申请利率 **3.5%**
4. 贡献承诺录一条（存款日均/目标余额/目标值 200 万）
5. 提交预览 → 路由预览：**预期"支行行长终审"**（3.5≥挂牌价 3.4）
6. 提交 → 差异确认弹窗确认 → 提示申请号
7. `wangwu` 登录 → 利率审批 → 该申请"核验资料"弹层可见摘要 → 进入完整审批
8. 检查详情页区块：来源徽标=冻结快照（绿）、资料校验通过、路由步骤条当前在支行行长
9. 操作区直接点"通过"（不调价）→ 预期：终审通过，状态 APPROVED_LEVEL
10. 断言：历史审批档案中该申请已有**决议**（ISSUED）且**承诺计划已生成**（贡献度跟踪页可见）

## 场景 B：对公国企存量调息——逐级上送

1. `zhangsan` 发起：客户 CUST002，选"存量调息"，选合同 LC20260002（原利率 4.20%）
2. 申请利率填 **3.9%**（降幅 30BP，不超 GM 权限）→ 路由预览预期：**部门总经理终审**（链：支行→GM）
3. 提交 → `wangwu` 通过（过手）→ `deptgm` 登录审批通过 → 终审成立
4. 回到 zhangsan 再发起一笔同合同**不行**（一合同一有效分项，预期被阻断）——先让前一笔终态后再试
5. 变体：申请利率 **3.7%**（降幅 50BP）→ 预览预期分管行领导；**2.9%**（<3.0% 下限）→ 提交时被硬边界直接阻断

## 场景 C：个人经营性贷款

1. `zhangsan` 发起：客户类型"个人"，CUST101，存量调息选 LC20260003（4.50%）
2. 申请 **4.2%**（降幅 30BP>20 且≥3.8%）→ 预期路由：分管行领导（零售金融部链）
3. 申请 **3.7%**（<3.8%）→ 预期：小组表决路径
4. 提交后检查快照包冻结（详情页快照信息卡有冻结时间与数据日期）

## 场景 D：存款申请——账号反查与超上限上会

1. `zhangsan` → 存款利率申请 → 客户 CUST001（页面**无关联人员、无贡献度录入**）
2. 存量账户调价：账号输入 `9550880000000101` 失焦 → **预期自动带出**：对公定期/1 年/余额 1200 万/当前 1.25%；乱输账号提示未命中但不阻断
3. 申请利率填 **1.25%**（=上限）→ 预览预期：**支行行长终审**（等于上限不上会）
4. 再改 **1.30%**（>1.25%）→ 预览预期：上会小组
5. 用 1.30% 提交 → `wangwu` 通过（过手）→ 自动建表决批次；审批详情显示存款账户卡+上限比对，**无贡献度卡片**
6. 拟开户变体：账户方式改"拟开户方案"，不填账号也可提交

## 场景 E：集团申请（B18 防拆分 + 额度勾稽）

1. `zhangsan` → 贷款申请 → 客户类型"集团客户"，输入 GROUP001 → 带出集团授信（1 亿/已分配/可用）
2. 勾选 MEMBER_A，申请金额 **4000 万**，期限 1Y，利率 3.3%
3. 路由预览：**预期金额档按集团批复 1 亿=≥5000万档**（不是按 4000 万走低档）
4. 把 MEMBER_A 申请金额填 **7000 万**（超其 6000 万额度）→ 提交预期被额度勾稽阻断
5. 正常提交后：审批详情页集团区块=先汇总（成员数/合计金额）再折叠展开成员明细

## 场景 F：六人表决与行长决策

1. 用场景 B 步骤 5 的 3.7% 个人申请（或任何上会单）
2. `committee`~`committee6` 六个账号依次登录 → 表决页 → 逐项投票
   - 投 4 个赞成 + 2 个反对 → **预期计票通过（≥4）**
   - 页面只显示本人选择与提交状态，看不到他人票型
   - 重复提交同一票 → 预期幂等拦截
3. `auditor` 登录 → 审计管理 → 投票人反查：能看到真实投票人+票型+匿名码对照
4. `president` 登录 → 待决策 → 详情可见汇总票数+"六人小组表决意见（匿名）"折叠块
5. 点"一票否决"不填意见 → 拒绝；填意见后否决 → 分项 VETOED
6. 再上会一笔，行长"同意利率"→ FINAL，决议+承诺计划自动生成

## 场景 G：决议回填与两级核验

1. 对场景 F 通过的决议（决议列表可查）执行合同回填：
   - 正确利率回填 → 自动核验 → EXECUTED
   - 利率填错 → 直接拒绝（七项校验）
   - 金额小于决议金额 → 拒绝（≥ 校验）
2. CUST002 的合同 LC20260002 若走完决议回填：借据 NB_C202（4.35≠4.20）→ **预期 RECONCILE_EXCEPTION**，通知列表（顶栏铃铛）有核验异常提醒，且同一决议重复触发不产生重复通知

## 场景 H：否决与关联重提（D18b）

1. 把场景 A 的申请在支行行长节点否决（填原因）→ 主申请 REJECTED
2. `zhangsan` → 历史申请 → 该单点"关联重提"→ 预期生成新申请号并带入全部数据
3. 新草稿编辑保存 → 继承分项（已批准项）**不应丢失**
4. 重提提交 → 原申请状态变 RETURNED，新申请重新走完整路由
