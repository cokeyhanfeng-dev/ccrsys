## 5. 首期开发范围建议(本次开发)

本次开发先落地 **M0–M3** 里程碑,含:

1. **数据库**:建库 + 全部外部数据表(`caps_*`/`dw_*_snapshot`)+ 全部业务表(`ccr_*`)DDL。
2. **外部数据清单**:独立文档 + DDL,作为数仓对接契约(见《外部数据支撑表结构与清单》)。
3. **后端骨架**:RuoYi-Vue-Plus 5.x 多模块工程、统一返回/异常/加密/幂等、登录认证、字典参数基础能力。
4. **前端骨架**:Vue 3 + Element Plus 登录/布局/菜单。
5. **Docker 构建**:JDK17+Maven 容器编译通过。

后续里程碑按依赖关系迭代推进,详见任务清单。
