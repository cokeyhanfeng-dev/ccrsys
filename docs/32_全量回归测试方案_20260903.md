## 二、接口冒烟清单（L3，admin token）

- 认证：`POST /auth/login` 正确/错误密码
- 申请：`GET /ccr/applications`、`GET /ccr/applications/{id}`、`POST /ccr/applications`（非客户经理应 403）
- 审批：`GET /ccr/approval/tasks`、`GET /ccr/approval/{applicationId}/detail`
- 承诺：`GET /ccr/commitments/tracks`、`/tracks/{id}`、`/org-achievement?customerNo=`
- 配置：`GET /system/flow/thresholds/lpr`、`/thresholds/matrix`、`/thresholds/product-limit`、`/system/flow/definitions`
- 系统：`GET /system/users`、`/system/depts`、`/system/cache-configs`、审计 `/system/flow/thresholds/change-log`
- 数仓/客户：`GET /ccr/customers?keyword=`、`GET /ccr/products/rate-limits`
- 越权负例：客户经理访问 admin 接口应 403
