# 对公贷款按金额三档路由 · 需求文档

> 状态:已实施定稿(2026-08-14)。本文件为"对公贷款三档路由"细化说明;**综合需求清单以 `docs/10_里程碑需求汇总.md` 为准**。

## 0. 定稿口径(2026-08-14 用户确认,已实施)

- **≥5000万**:保持不变(现状对公链路)。
- **1000万–5000万(含1000万)**:按原 <5000万 链路走(现状对公链路)。
- **<1000万**:存量走零售金融部→零售金融部分管领导;新增走授信评审部→授信评审部分管领导;利率区间与个人贷款一致。
- **链路形态(用户确认)**:三档统一走**完整链路**(与个人贷款一致)——`BRANCH_MANAGER`(必经)→`DEPT_GENERAL_MANAGER`→`VICE_PRESIDENT`→`SIX_PEOPLE_GROUP`(兜底),按利率边界链式(权限内提前终审);`<1000万` 档存量命中部门=**零售金融部(org_code 3202233991)**、新增命中部门=**授信评审部(org_code 3202233943)**,部门仅分流**节点内处理人**(链路形态不变)。
- **金额定档(用户确认)**:一律按**申请/分项金额**定档(`amountBasis=APPLY_AMOUNT`,不再集团授信总额优先)。
- **叠加需求(贷审会秘书岗)**:1000万以上所有贷款,申请利率 <2.6% 时,分管行长审批后增加贷审会秘书岗(审核岗,否决即整单拦截),审核完毕后再走六人小组(详见 `docs/10_里程碑需求汇总.md` §四,已实施)。

## 1. 背景与目标

对公贷款按**申请金额**分三档路由:

| 档位 | 金额区间 | 链路 |
|---|---|---|
| 1 | **≥5000 万(含)** | 保持不变(现状对公链路) |
| 2 | **1000 万–5000 万(含 1000 万)** | 按原 <5000万 链路走(现状对公链路) |
| 3 | **<1000 万** | 见下表,**存量/新增分两条部门链路,利率区间与个人贷款一致** |

### <1000 万档

| 存量/新增 | 链路 | 利率区间 |
|---|---|---|
| **存量贷款** | 零售金融部 → 零售金融部分管领导审批 | 与个人贷款一致 |
| **新增贷款** | 授信评审部 → 授信评审部分管领导审批 | 与个人贷款一致 |

> 用户原话:"1000 万以下的对公贷款:1. 存量贷款走零售金融部,然后报零售金融部的分管领导审批。2. 新增贷款还是走授信评审部,然后再报授信评审部的分管领导审批。其利率区间跟个人贷款是一样的。"

## 2. 实施前现状(实测依据)

- 矩阵 `ccr_rate_matrix.amount_tier` 仅 `LT_5000`(<5000万)/`GE_5000`(≥5000万)两档;定档基准默认**集团授信总额**,无则退**申请金额**。
- 对公存量 EXISTING(部门=**公司金融部(org_code 3202233912)**):<5000万 → 部门总经理→分管领导→小组;≥5000万 非国企 GM 无权限。
- 对公新增 NEW(部门=**授信评审部(org_code 3202233943)**):非国企<5000万 支行行长有终审权,其余 GM→VP→小组。
- 个人贷款 LOAN_PERSONAL(部门=存量**零售金融部(org_code 3202233991)**/新增**授信评审部(org_code 3202233943)**):BM→GM→VP→GROUP 链式;新增边界 BM/GM=LPR+100BP(4.0%)、VP=LPR+80BP(3.8%);存量 GM 降幅0-20BP floor3.8%、VP floor3.8%。
- 路由引擎按 priority 链式匹配:`BRANCH_MANAGER`(必经,链首固定)→`DEPT_GENERAL_MANAGER`→`VICE_PRESIDENT`→`SIX_PEOPLE_GROUP`(兜底)。

## 4. 实施要点(已落地)

- **金额档三档化**:`RateMatrixRouterImpl` 定档从"5000 单阈值"扩为 **1000/5000 双阈值三档**——`toAmountTier()` 映射 `LT_1000`/`GE_1000_LT_5000`/`GE_5000`;`match()`/`voteConditionHit()` 同步。
- **矩阵种子**(`db/07_rate_matrix.sql`):原 `LT_5000` 37 行统一改档 `GE_1000_LT_5000`(维持原 <5000万 链路不变);新增 **15 行 `LT_1000` 对公行(9801-9815)**:存量 dept=3202233991、新增 dept=3202233943,利率边界按个人贷款口径。
- **配置界面**(`params.vue`):金额档下拉/voteCondition 构造器/voteConditionText 三档化;`dict.ts AMOUNT_TIER` 三档文案。
- **测试文档**:`docs/06_测试方案.md`/`docs/07_手工测试用例.md` 三档场景同步。
