# 在线用户清单

## 使用方式

管理员登录 PC 后打开「系统管理 → 在线用户」（`/system/online`）。按有效登录会话展示工号、姓名、机构、当前主角色、电脑/移动终端、登录时间、最近访问时间、登录 IP；支持工号/姓名关键词、机构精确匹配、终端筛选及分页。查询、重置和手动刷新都会重新获取会话快照。

符合条件的在线人数按账号去重，会话数按登录凭证分别计算，同一个人使用电脑和手机会显示两行。列表按最近访问时间倒序排列，无时间的旧会话排在末尾。本期仅查询，不提供强制下线。

## 在线口径

- 会话由 Sa-Token 和 Redis 现有数据判断：登录映射仍有效、未超过绝对有效期/空闲有效期，且本地账号仍启用、未删除。
- 关闭页面不会立即注销会话；最近访问时间包含页面自动请求，不代表人员正在手动操作。
- 仓库默认会话总有效期为 86400 秒，空闲有效期 7200 秒；实际以部署配置为准。
- PC 主动退出先调用 `/auth/logout` 注销当前会话，成功后清理本地身份并跳转登录；网络失败保留身份供重试。移动端已有注销调用，不改变其协议。
- 账号级会话和 Token 会话区分：新增登录时间、IP 写入各自 TokenSession，多端登录不相互覆盖。
- 上线前已存在的会话可以列出，但缺失登录时间/IP 时展示「—」，不把查询时间当作登录时间。下次登录时补齐。
- 会话列表是查询时快照；读取期间退出、登录会使总数短暂变化，可手动刷新。请求结束后发生的退出不追溯修改已显示列表。

## 接口与权限

`GET /system/online-users`，仅 `admin` 可访问，沿用 `/system/**` 拦截器并增加控制器注解和服务内角色校验。响应 `Cache-Control: no-store`。

| 参数 | 含义 |
| --- | --- |
| pageNum | 页码，默认 1，最小 1 |
| pageSize | 每页数量，默认 20，范围 1～100 |
| keyword | 工号/姓名关键词，最多 64 字符，去除首尾空白后匹配 |
| orgId | 机构 ID，正数；只匹配该机构 |
| client | PC / MOBILE，省略或空值为全部 |

返回统一 `R`，data 包含 `total`（筛选后的会话数）、`userCount`（筛选后的去重人数）、`records`、`queriedAt`。每行只返回展示字段，不返回 token、TokenSession、Redis key 或密码。角色展示本地账号当前主角色。

Redis 只使用当前 StpLogic 生成的登录 token 前缀，通过 SCAN 枚举并去重，再读取有效期和会话元数据；查询不建立 TokenSession、不刷新会话活跃时间、不续期。避免使用 Sa-Token 1.38 默认搜索内部的 KEYS。最多读取 20000 个去重 token key，超过上限明确报错，禁止把截断结果展示成完整人数。用户/角色/机构按去重账号每 500 个批量读取。Redis 或数据库失败时接口报错，前端显示加载失败，不把故障显示为零人在线。

## 验证与上线

- `./dev verify`：后端 550 项全部通过，含新增会话读取 4 项、列表服务/权限/校验 5 项；PC 24 项、移动 42 项全部通过，两端生产构建成功。
- 新增前端 5 项覆盖组合筛选与计数、会话减少时分页回退、错误提示、响应乱序、注销成功顺序及失败保留/单点初始化兼容。
- `./dev app-up`、`./dev smoke`：本轮因 Docker Desktop 未运行被环境预检阻断，未完成真实 Redis/HTTP 和浏览器联调。
- 工具版本：JDK 17.0.20、Maven 3.9.11、Node v25.1.0、npm 11.18.0。
- 无 DDL、新端口、环境变量或数据卷；不运行 reset，不重建数据。未打包部署生产。
- 本功能上线更新后端和 PC（`./dev release 12`）；移动会话的元数据采集由后端统一执行，无需为本功能更新移动静态资源。如果包含前一次尚未上线的移动单位修复，应按累计改动选择 `123`。

运行态验收：同账号 PC/移动各登录一次，管理员应看到 1 人/2 会话；PC 退出后只移除 PC 行；空闲超时/令牌失效排除；查询不延长被查看会话有效期；旧会话无新增字段时正常展示；普通业务角色直接请求接口返回 403；机构/姓名/终端组合筛选与分页计数一致；Redis 中断时显示错误。正式环境 IP 依赖现有可信代理转发配置，沿用系统登录日志的客户端 IP 取值方式。
